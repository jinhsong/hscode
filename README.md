# 수입모델 인증 확인 프로그램 (KC 안전인증 · 전파인증)

수입하는 전자제품의 **모델 코드**(예: `SM-X300akak`)를 입력하면,
그 제품이 아래 두 가지 인증을 받았는지 **자동으로 찾아서 표로 보여주는** 프로그램입니다.

1. **KC 전기용품 안전인증**
2. **전파인증** (방송통신기자재 적합성평가)

여러 모델을 한 번에 붙여넣거나 엑셀(CSV) 파일로 올리면, 모델마다 인증 여부를 한눈에 확인하고
결과를 다시 CSV로 내려받을 수 있습니다.

> 💡 **이 프로그램이 필요한 이유**
> 내가 수입하는 모델 코드는 `SM-X300akak`처럼 **긴 전체 코드(full code)** 인데,
> 인증 데이터베이스에는 보통 `SM-X300`(기본 코드)이나 `SM-X306`(파생 모델)처럼 **짧게** 등록돼 있습니다.
> 그래서 단순 검색으로는 안 나오고, 이 프로그램이 **"내 전체 코드가 어떤 기본/파생 코드로 시작하는지"**
> 를 자동으로 맞춰서 찾아줍니다.

# 1. 준비물 (딱 한 번만)

이 프로그램은 **Python**(파이썬)이라는 무료 프로그램 위에서 돌아갑니다.
컴퓨터에 Python이 깔려 있어야 합니다. **한 번만 설치하면 됩니다.**

## 1-1. Python 설치 여부 확인

먼저 **명령어 입력 창**을 엽니다.

- **Windows**: 키보드 `⊞ Win` 키 → `cmd` 입력 → **명령 프롬프트** 실행
- **Mac**: `⌘ + Space` → `터미널` 입력 → **터미널** 실행

창이 열리면 아래를 입력하고 `Enter`:

```bash
python --version
```

- `Python 3.10.0` 처럼 **숫자가 나오면** 설치된 것입니다 → **1-3으로 건너뛰세요.**
- `'python'은(는) ... 명령이 아닙니다` 같은 **오류가 나오면** 아래 1-2로 진행합니다.
  (Mac에서는 `python3 --version` 도 한번 해보세요.)

## 1-2. Python 설치 (없을 때만)

1. 웹브라우저에서 **<https://www.python.org/downloads>** 접속
2. 노란색 **Download Python** 버튼 클릭 → 설치 파일 실행
3. ⚠️ **(Windows 매우 중요)** 설치 첫 화면 맨 아래
   **`Add python.exe to PATH`** 체크박스를 **반드시 체크**한 뒤 `Install Now` 클릭
4. 설치가 끝나면 명령어 창을 **새로 열어** 다시 `python --version` 확인

## 1-3. 프로그램 파일 내려받기

이 프로젝트 폴더(`hscode`)를 컴퓨터에 가져옵니다. 둘 중 편한 방법:

- **방법 A (간단)**: GitHub 저장소 페이지에서 초록색 **`Code` → `Download ZIP`** →
  내려받은 zip 압축 풀기 → 폴더 이름 기억 (예: `C:\hscode` 또는 `~/hscode`)
- **방법 B (git 사용 시)**:
  ```bash
  git clone https://github.com/jinhsong/hscode.git
  ```

# 2. 프로그램 실행하기 (3단계)

명령어 창(명령 프롬프트 / 터미널)에서 아래 **3개 명령을 순서대로** 입력합니다.

### ① 프로그램 폴더로 이동

`cd` 뒤에 폴더 경로를 적습니다. (경로는 본인이 압축 푼 위치로 바꾸세요)

```bash
cd C:\hscode
```
> Mac/Linux 예시: `cd ~/hscode`
> 💡 팁: `cd ` (한 칸 띄우고) 까지 입력한 뒤, 폴더를 창으로 끌어다 놓으면 경로가 자동 입력됩니다.

### ② 필요한 부품 설치 (처음 한 번만)

```bash
pip install -r requirements.txt
```
> 잠시 여러 줄이 주르륵 나오고 멈추면 설치 완료입니다.
> `pip`이 안 되면 `python -m pip install -r requirements.txt` 로 시도하세요.

### ③ 프로그램 켜기

```bash
python app.py
```

아래 비슷한 글자가 나오면 **성공**입니다. (창은 그대로 켜 두세요)

```
 * Running on http://127.0.0.1:5000
```

이제 **웹브라우저(크롬/엣지 등)** 주소창에 아래를 입력하고 접속하세요:

```
http://127.0.0.1:5000
```

> 🔚 **프로그램 끄기**: 명령어 창에서 `Ctrl + C` 를 누르면 종료됩니다.
> 다음에 다시 켤 때는 ①(폴더 이동)과 ③(`python app.py`)만 하면 됩니다. ②는 생략 가능.

# 3. 웹 화면 사용법

브라우저에 화면이 뜨면:

1. 가운데 **큰 입력칸**에 모델 코드를 **한 줄에 하나씩** 붙여넣습니다.
   ```
   SM-X300akak
   SM-X306abc
   SM-S921xyz
   ```
   또는 **`파일 선택`** 버튼으로 엑셀에서 저장한 **CSV 파일**을 올립니다.
   (예시 파일: 프로젝트 안 `samples/models.csv`)
2. **`조회`** 버튼을 클릭합니다.
3. 아래에 모델별 결과 표가 나타납니다.
4. **`결과 CSV 내려받기`** 를 누르면 표 전체를 파일로 저장합니다.

> ℹ️ 화면 위 안내줄이 현재 연결 상태를 알려줍니다.
> - **전파인증**: 별도 설정 없이 **처음부터 실제 정부 데이터(EMSIT)로 조회**됩니다. (키 불필요)
> - **KC 안전인증**: 키를 넣기 전에는 **데모(샘플값)** 로 표시됩니다.
>   실제 데이터로 바꾸려면 → [5번 항목](#5-실제-인증-데이터에-연결하기-선택)
>
> ⚠️ 단, 전파인증 실제 조회는 인터넷 연결이 필요하며 `emsit.go.kr` 접속이 가능해야 합니다.
> (회사 방화벽 등으로 막혀 있으면 ⚠️ 조회실패로 표시될 수 있습니다.)

# 4. 결과 보는 법

표는 **KC 안전인증** 칸과 **전파인증** 칸으로 나뉘고, 각 칸에 아래 중 하나가 표시됩니다.

| 화면 표시 | 뜻 | 어떻게 해야 하나 |
|---|---|---|
| ✅ **인증됨** | 인증을 받은 제품을 찾았습니다 (매칭된 모델명·인증번호 표시) | OK. `공식 원본 확인 ↗` 링크로 한 번 더 대조 가능 |
| 🟦 **인증됨 (basic 매칭)** | 내 전체 코드가 **기본 코드로 시작**해서 인증 확인됨 (가장 흔한 경우) | OK |
| 🟠 **유사 (확인필요)** | 비슷하지만 확실치 않음 | 사람이 직접 원본을 확인하세요 |
| ❌ **인증 없음** | 조회는 됐지만 해당 인증 기록이 없음 | 인증이 안 된 제품일 수 있음 — 주의 |
| ⚠️ **조회실패** | 통신 오류로 **확인 자체가 안 됨** | "인증 없음"으로 오해 금지. 잠시 후 다시 시도 |

> 🛑 **중요**: ⚠️ 조회실패(error)와 ❌ 인증 없음(not_found)은 **완전히 다릅니다.**
> 조회실패는 "모름"이지 "인증 안 됨"이 아닙니다. 컴플라이언스 판단 시 꼭 구분하세요.

# 5. 실제 인증 데이터에 연결하기 (선택)

| 인증 | 실제 조회에 필요한 것 |
|---|---|
| **전파인증** | **없음.** 키 없이 EMSIT 공개 API로 처음부터 실제 조회됩니다. |
| **KC 안전인증** | 공공데이터포털 **무료 인증키** (아래 절차) |

> 즉, 전파인증만 쓰실 거면 **아무 설정도 필요 없습니다.** KC까지 실제로 보려면 아래를 따라 하세요.

### 5-1. KC용 인증키와 주소 발급받기

1. **공공데이터포털**(<https://www.data.go.kr>)에 가입/로그인합니다.
2. **국가기술표준원 제품 안전인증 및 리콜 정보** (`data.go.kr/data/15116894`)를 검색해
   **`활용신청`** 버튼을 누릅니다. (보통 즉시 승인)
3. 승인 후 **마이페이지 → 데이터활용 → 인증키**에서 **일반 인증키(Decoding 권장)** 를 복사합니다.
4. 그 데이터 **상세 페이지**에서 **`요청주소(End Point)`** 도 복사해 둡니다.

### 5-2. 프로그램에 키 넣기

프로그램 폴더 안의 **`.env.example`** 파일을 복사해 **`.env`** 라는 파일을 만듭니다.

```bash
cp .env.example .env
```
> Windows에서는 메모장으로 `.env.example`을 열어 **다른 이름으로 저장 → 파일 이름 `.env`**
> (파일 형식: **모든 파일**)로 저장해도 됩니다.

그리고 `.env` 파일을 메모장으로 열어 KC 관련 두 줄만 채웁니다 (전파인증 줄은 비워두면 됩니다):

```ini
DATA_GO_KR_SERVICE_KEY=여기에_발급받은_인증키_붙여넣기
KC_API_URL=여기에_KC인증_요청주소_붙여넣기
```

저장한 뒤 프로그램을 **다시 켜면**(`python app.py`) KC도 실제 데이터로 바뀝니다.

> ⚙️ KC 결과가 비어 나오면, data.go.kr 상세의 **요청변수/출력결과** 항목 이름이 기본값과
> 다를 수 있습니다. 그 경우 `cert_client.py` 맨 위 `ENDPOINTS["kc"]` 의
> `search_param`, `*_field` 값만 사이트 표기에 맞게 바꾸면 됩니다. (도움 필요 시 문의)

> 🛰️ **전파인증 동작 방식**: `cert_client.py` 의 `EMSIT_RRA_URL`(getAuthInfo.do)로
> 기본모델(`matlBscMdlNm`)·파생모델(`matlDerivMdlNm`)을 검색해 XML 응답을 해석합니다.
> 키가 필요 없으며, 다른 주소로 바꾸려면 `.env` 의 `RRA_API_URL` 만 채우면 됩니다.

# 6. 자주 묻는 문제 (오류 해결)

| 증상 | 해결 |
|---|---|
| `'python'은(는) 명령이 아닙니다` | Python 미설치 또는 PATH 미체크 → [1-2](#1-2-python-설치-없을-때만) 재설치 (PATH 체크!) |
| `'pip'은(는) 명령이 아닙니다` | `python -m pip install -r requirements.txt` 로 대체 |
| `No module named flask` | ② 설치 단계(`pip install -r requirements.txt`)를 안 했음 → 다시 실행 |
| 브라우저에서 페이지가 안 열림 | ③ `python app.py` 창이 **켜진 상태**인지 확인. 주소 `http://127.0.0.1:5000` 정확히 입력 |
| `Address already in use` (포트 사용 중) | 다른 창에서 이미 켜져 있음. 그 창에서 `Ctrl+C` 후 다시 실행 |
| 결과가 전부 ⚠️ 조회실패 | 인터넷/인증키 확인. 데모 모드면 정상 동작해야 함 |
| 한글이 깨진 CSV | 엑셀에서 **CSV UTF-8** 형식으로 저장 |

> 정상 작동 자가진단: 폴더에서 `python test_matching.py` 실행 → `PASS` 가 여러 줄 나오면 OK.

# 7. 참고: 동작 원리와 파일 구성

## 매칭 방식

| 매칭 유형 | 의미 | 예 |
|---|---|---|
| `exact` | 완전 일치 | `SM-X300` = `SM-X300` |
| `prefix` | 내 full code 가 인증 모델로 시작 (가장 흔함) | `SM-X300akak` ⊃ `SM-X300` |
| `reverse_prefix` | full code 가 인증 모델의 접두 (약한 매칭) | 참고용 |

- 하이픈/공백 차이는 무시하고 비교합니다 (`SM-X300` = `SMX300`).
- 오탐 방지를 위해 `prefix` 매칭은 일치 길이가 `MIN_PREFIX_LEN`(기본 5) 이상일 때만 인정합니다.

## 결과 상태(status) 값

| status | 의미 |
|---|---|
| `certified` | 인증 확인됨 (exact/prefix) |
| `review` | 유사 매칭, 사람 확인 필요 |
| `not_found` | 조회됐으나 인증 없음 |
| `error` | API 오류로 확인 불가 |
| `skipped` | API 주소 미설정 |

| `Dockerfile`, `.github/workflows/ci.yml` | 컨테이너 빌드 · 자동 검사 |
